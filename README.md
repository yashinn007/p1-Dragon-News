<h1>Project name: Dragon News</h1>
<p> Description: On this website, we can see some news based on categorys. If we want to see news details we have to login/register. 
We can Login with email-password or google or github. (User data will saved in mongoDB server)</p>

<h2>Technologies:</h2>
1. Next.js,<br/>
2. Tailwind CSS,<br/>
3. Better Auth,<br/>
4. React Hook form,<br/>
5. MongoDB etc

<h2>Features:</h2>
1. Applying group layout (Auth, Main),<br/>
2. Applying different fonts in layout (poppins,montserrat),<br/>
3. apply marquee as breaking news,<br/>
4. apply current date from date-fns,<br/>
5. Apply react hook form for get data,<br/>
6. configer dns for mongodb 'server-error',<br/>
7. setup email-password, google & github signin,<br/>
7. Add proxy for authorization.
